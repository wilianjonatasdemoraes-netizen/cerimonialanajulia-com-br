# GOOGLE-BUSINESS-PROFILE-SEO

Como configurar o Perfil da Empresa no Google (Google Business Profile) e conectá-lo ao site.

> Preencha somente com informações reais. Não cadastre endereço, horários ou serviços que não
> correspondam ao atendimento real — inconsistências prejudicam o ranqueamento local.

## 1. Criar ou reivindicar o perfil

1. Acesse <https://business.google.com>.
2. Busque por "Ana Júlia Cerimonial" — se já existir uma ficha, clique em **Reivindicar**.
3. Caso não exista, clique em **Adicionar empresa**.

## 2. Dados a preencher

| Campo | Valor |
| --- | --- |
| Nome | Ana Júlia Cerimonial |
| Categoria principal | Serviço de organização de eventos / Cerimonialista |
| Categorias secundárias | Planejador de casamentos, Organizador de festas |
| Telefone / WhatsApp | (37) 99926-5472 |
| Site | https://cerimonialcasamentos.com.br |
| Instagram | https://www.instagram.com/Anajuliacerimonialista |
| Endereço | **Somente se houver endereço comercial real com atendimento ao público** |
| Área atendida | Pará de Minas, Divinópolis, Nova Serrana, Itaúna e região Centro-Oeste de MG |
| Horário | Preencher com o horário real de atendimento |

Se o atendimento for feito sem loja física (a maioria dos cerimonialistas), escolha
**empresa com área de atendimento** e oculte o endereço — o Google permite esse formato.

## 3. Serviços a cadastrar

- Cerimonial de casamento
- Assessoria de casamento
- Organização de casamento
- Cerimonial de debutantes
- Organização de festa de 15 anos
- Assessoria e planejamento de eventos

Em cada serviço, use a descrição da página correspondente do site e adicione o link:

| Serviço | Link |
| --- | --- |
| Cerimonial de casamento | /cerimonial-de-casamento |
| Assessoria de casamento | /assessoria-de-casamento |
| Cerimonial de debutantes | /cerimonial-debutantes |
| Festa de 15 anos | /festa-de-15-anos |

## 4. Conectar ao site

- O site já publica dados estruturados `LocalBusiness` com nome, telefone, cidade e área
  atendida — os dados do perfil devem ser **idênticos** (mesmo nome e mesmo telefone).
- Adicione o link do site no perfil e o link do perfil no rodapé do site (já existe um botão
  "Google Business" no rodapé — atualize-o com a URL definitiva da ficha quando ela existir).

## 5. Rotina de manutenção

- Publicar fotos reais de eventos (com autorização) todo mês.
- Publicar novidades/posts com os artigos do blog.
- Responder todas as avaliações.
- Solicitar avaliações aos clientes após cada evento — nunca comprar ou criar avaliações.
- Manter horários atualizados em datas especiais.
